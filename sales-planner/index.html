API:erna bakom lösningen

Ett API gör det möjligt för webbappen att automatiskt hämta information från en annan tjänst. Här används två API:er och informationen kombineras till ett gemensamt resultat.

API 01

Open-Meteo

Hämtar aktuell temperatur, nederbörd och väderinformation för den valda staden.

API 02

Frankfurter

Hämtar aktuell valutakurs och räknar om produktpriset från SEK till marknadens lokala valuta.
